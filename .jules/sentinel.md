## 2026-04-10 - Sensitive Data Exposure in Debug Logs
**Vulnerability:** The `VueSocketIOLogger` class in `src/logger.js` previously passed un-sanitized event payloads directly to `window.console` when debug mode was enabled. This could lead to sensitive information (like passwords or authentication tokens) being exposed in the browser's developer console.
**Learning:** Even diagnostic or debug-only logging mechanisms can pose a risk if they automatically broadcast unstructured application state. Client-side libraries that act as middleware (like Socket.io integrations) often handle payloads containing authentication credentials during initial connection or specific events.
**Prevention:** Implement a recursive sanitization mechanism on the logger class to intercept and redact known sensitive keys (`/password|token|secret|credential|key|auth/i`) from objects and arrays before they are passed to the native console logging functions, safely handling circular references.
