## 2026-03-02 - [Data Leakage via Unsanitized Logging]
**Vulnerability:** The logger class `src/logger.js` printed the entirety of arguments indiscriminately when debug mode was enabled. Because Socket.io handles numerous kinds of payloads, and `event` or `info` are often used by devs passing state around, sensitive data (like tokens, passwords) could easily leak into the browser console logs or error monitoring tools configured to aggregate console errors.
**Learning:** Even though logging is often a dev-only tool, front-end loggers that capture application-wide state (like a vuex adapter for sockets) can be a vector for data leakage when left in debug mode in staging or via user-submitted diagnostic reports.
**Prevention:** Always sanitize structured data before passing it to native `console` methods by replacing keys that match known sensitive patterns (like `/password|token|secret|credential|key|auth/i`) with `[REDACTED]`. Care should be taken to handle circular references in arbitrary objects.
