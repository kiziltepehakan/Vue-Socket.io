## 2024-11-07 - Log Sanitization for Sensitive Data
**Vulnerability:** The logger (`src/logger.js`) in vue-socket.io logged data payloads broadly without checking for sensitive keys (like passwords, tokens, auth keys). If Socket.io events carried such sensitive data, it would inadvertently leak them into the browser console logs, risking exposure.
**Learning:** It is crucial to sanitize all arguments recursively before passing them to the underlying logging mechanism, especially in real-time integrations like websockets where potentially vast and structured state sync packets pass through a central emitter or logger. Special care is needed for circular references and standard object instances (`Error`, `Date`, etc.) to prevent infinite loops or destroying observability.
**Prevention:** Always implement a dedicated `sanitize` or `redact` hook inside the core logger classes in a library, filtering typical secret fields matching `/password|token|secret|credential|key|auth/i`, before the payload is persisted or displayed in client or server logs.
