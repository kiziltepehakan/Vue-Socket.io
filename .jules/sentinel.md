## 2023-10-27 - [Exposed Sensitive Data in Logs]
**Vulnerability:** The logger class `VueSocketIOLogger` was printing all incoming and outgoing socket data directly to the browser console. This could include sensitive data like passwords, tokens, or credentials if the socket application was transmitting them.
**Learning:** WebSocket payloads often include authentication tokens or user credentials when establishing connections or performing sensitive actions. If a generic logging interceptor logs all events and payloads indiscriminately, these secrets will be persisted in plain text within the browser's developer tools console, potentially exposing them to physical shoulder surfing, malicious browser extensions, or XSS attacks that scrape the console object.
**Prevention:** Always implement a sanitization layer in client-side generic loggers before passing objects to `console.*`. The sanitizer should safely redact keys matching sensitive keywords (e.g., password, secret, token, auth, key) while avoiding crashes from circular references or non-plain objects.
