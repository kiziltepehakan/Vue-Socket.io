## 2024-05-15 - [Exposed Sensitive Data in Logs]
**Vulnerability:** The logger in `src/logger.js` indiscriminately logs all incoming socket events and data (including plain text passwords, tokens, auth keys) because it takes `args` / `data` and prints them out to `window.console` directly without sanitization. In a Vue app, logging sensitive data to the browser console can lead to exposing secrets to malicious extensions or anyone looking at the dev tools.
**Learning:** `vue-socket.io-v4` doesn't sanitize data in `src/logger.js` before calling `console.info`, `console.error`, `console.warn`. Because it logs every broadcast event and dispatch event in `src/emitter.js`, this poses a significant risk of data leakage for applications exchanging sensitive data over sockets (e.g. login).
**Prevention:** Always implement a sanitization mechanism for objects/arrays that are logged, masking keys that contain words like `password`, `token`, `secret`, `credential`, `key`, `auth`.
