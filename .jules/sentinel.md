## 2024-06-20 - Sensitive Data Exposure in Browser Debug Logs
**Vulnerability:** The logger utility (`VueSocketIOLogger` in `src/logger.js`) previously logged arbitrary objects directly to `window.console` during socket events. This can inadvertently leak sensitive authentication payloads, tokens, passwords, or secrets if debug mode is enabled by the developer in production or during live testing.
**Learning:** Browser console logging utilities in libraries must assume that client-supplied payloads might contain sensitive data and should be defensively sanitized. Standard `console.log` behavior deeply serializes objects, posing a major risk of credentials disclosure in debug environments.
**Prevention:** Implement a recursive data sanitization method within the core logger to redact keys matching known sensitive patterns (e.g., `password`, `token`, `secret`) before passing objects to native console methods. Ensure circular references are safely handled during sanitization to avoid freezing the main thread.
