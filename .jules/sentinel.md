## 2026-04-19 - Sensitive Data Leakage in Vue-Socket.io Logger
**Vulnerability:** The `VueSocketIOLogger` class was directly logging the payload of socket events, warnings, and errors to `window.console` when debug mode was enabled. Because Socket.io frequently handles sensitive transactions (like authentication tokens or passwords during login), this caused a severe data leakage vulnerability where secrets could be exposed in the browser's developer console or captured by third-party tracking scripts.
**Learning:** Even debugging tools must practice data minimization and have defensive guardrails. Directly dumping objects to the console, while convenient, bypasses all application-level data protection boundaries. Additionally, sanitizing data for logging requires careful handling of circular references to avoid crashing the logger itself.
**Prevention:** Always implement a sanitization layer for logging utilities that automatically redacts known sensitive keys (e.g., matching `/password|token|secret|credential|key|auth/i`) and limits the depth or type of logged objects.
