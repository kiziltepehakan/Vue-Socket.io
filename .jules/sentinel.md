## 2024-05-19 - [Data Exposure in Real-Time Logging]
**Vulnerability:** The `VueSocketIOLogger` class was logging real-time socket packet data directly to the browser console without sanitization when debug mode was enabled. Because Socket.io payloads often carry sensitive information like authentication tokens, passwords, and PII, this created a high-risk data exposure vulnerability (e.g. leaking secrets to developer tools, analytics platforms, or browser extensions).
**Learning:** Generic logging systems in libraries that proxy live network traffic (like Vue-Socket.io) must implement data sanitization by default, as the library maintainer cannot predict what payloads consumers will transmit. Simply toggling a debug flag is insufficient protection.
**Prevention:** Implement recursive sanitization functions that filter out known sensitive keys (e.g., using regex `/password|token|secret|credential|key|auth/i`) on all logged plain objects and arrays before passing them to the console.
