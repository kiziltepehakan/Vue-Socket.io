## 2024-05-24 - Sensitive Data Exposure in Logs
**Vulnerability:** The `VueSocketIOLogger` previously printed all event payloads and logged data verbatim using `window.console`. This meant that sensitive data (e.g., passwords, authentication tokens) transmitted over sockets could be inadvertently leaked to the browser's debug console if logging was enabled.
**Learning:** In frontend environments (like Vue libraries), developers might enable debug mode in production or overlook that console outputs can be intercepted or remain in browser memory. Logging everything blindly exposes the application to data leakage.
**Prevention:** Implement an automatic sanitizer for all outgoing console logs that targets common sensitive fields using regex (`/password|token|secret|credential|key|auth/i`). Ensure that the sanitizer gracefully handles circular references, primitives, and complex non-plain objects (e.g., Error, Date) to prevent crashing the application while maintaining useful observability.
