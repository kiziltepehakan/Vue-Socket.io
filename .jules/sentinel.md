## 2026-08-04 - Exposed sensitive data in logs
**Vulnerability:** The logger printed out raw, unsanitized socket event data and arguments to `window.console`. Passwords, authentication tokens, and secrets passed through Socket.io events could be leaked to the client's browser console, which is highly visible.
**Learning:** Generic wrapper loggers that simply forward all arguments blindly to `console.log` or `console.info` without inspecting the payload represent a severe risk of data exposure. We need to actively sanitize keys that indicate sensitive data. We also have to be careful when sanitizing payload structures in JavaScript to handle circular references (via `WeakSet`) and skip non-plain objects to avoid crashes or freezing native/binary structures.
**Prevention:** Implement recursive sanitization on logger inputs that inspects object keys against a sensitive keyword regex (`/password|token|secret|credential|key|auth/i`). Use `WeakSet` to prevent `Maximum call stack size exceeded` errors on circular structures and only traverse plain arrays and objects.
