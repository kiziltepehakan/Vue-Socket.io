## 2026-04-14 - Sensitive Data Exposure in WebSocket Logs
**Vulnerability:** Indiscriminate logging of WebSocket payloads to the browser console. Any object properties containing passwords, tokens, or auth secrets were logged as plain text. This is a severe security issue because the browser console can be read by malicious browser extensions or other XSS attacks running on the same page.
**Learning:** Libraries bridging WebSocket connections to the frontend (like Vue-Socket.io) handle all inbound/outbound packets without inherent knowledge of their structure. Simply dumping `data` into `window.console.info` risks exposing everything. Additionally, payload logs often contain circular references, meaning simple `JSON.stringify` serialization or recursive sanitization logic will fail/crash without proper cycle detection.
**Prevention:** Implement a recursive sanitization utility with circular-reference detection (`Set`) applied specifically to plain objects and arrays to redact keys matching a sensitivity regex (`/password|token|secret|credential|key|auth/i`) before passing data to the console.
