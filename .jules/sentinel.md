## 2024-05-24 - [Exposed Sensitive Data in Logs]
**Vulnerability:** The logger (`src/logger.js`) in `vue-socket.io-v4` directly logged un-sanitized data via `console.info`, `console.error`, and `console.warn` when debug mode was enabled. This could expose sensitive user data, passwords, session tokens, or API keys directly to the browser console.
**Learning:** Even client-side loggers need strict data sanitization because debug modes can be enabled accidentally in production or exposed to malicious browser extensions. The issue existed because there was no data redaction layer before calling the browser's console API.
**Prevention:** Implement recursive data sanitization in logger utilities before data reaches the output sink. Specifically check object keys against a deny-list regex (e.g., `/password|token|secret|credential|key|auth/i`) and handle edge cases like circular references and built-in objects (Date, Error, RegExp) correctly to avoid breaking the application.
