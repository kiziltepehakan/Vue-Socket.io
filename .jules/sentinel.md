## 2026-07-22 - Prevent Sensitive Data Leakage in Logs
**Vulnerability:** The `VueSocketIOLogger` class would indiscriminately pass event arguments and arbitrary payloads directly to `window.console` (info, warn, error) when debugging was enabled. This could lead to exposing sensitive information (like passwords, auth tokens, secrets) into the browser console or log aggregators listening to `console`.
**Learning:** Logging logic that processes arbitrary structured data (objects/arrays) must proactively sanitize data structure before stringification or logging, otherwise it risks accidental leakage of sensitive keys, especially in real-time websocket integrations where payloads are broad.
**Prevention:** Implement a recursive sanitization mechanism on logged payload objects and arrays. Ensure safe-guarding against cyclic references (via `WeakSet`), processing of arrays, and targeting only plain objects to avoid traversing native or complex browser prototypes while filtering for sensitive key regexes.
