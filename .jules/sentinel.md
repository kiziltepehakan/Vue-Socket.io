## 2024-10-28 - Sensitive Data Leakage in VueSocketIOLogger
**Vulnerability:** The `VueSocketIOLogger` class (in `src/logger.js`) outputs raw data objects via `window.console` (info, warn, error, event). This can expose sensitive information (passwords, tokens, auth keys, etc.) in the browser console when used with debug mode enabled, leading to data leakage.
**Learning:** Even when `debug` mode is intended for developers, browser console logs can be persistent or viewed by third parties (or extensions) in production environments if left enabled. Data passed to loggers must be sanitized before output to prevent accidental exposure of sensitive keys in deeply nested structures.
**Prevention:** Implement an aggressive data sanitization mechanism for all logging output. The sanitizer should recursively traverse objects and arrays, safely mask keys containing terms like `password`, `token`, `secret`, `credential`, `key`, or `auth` with `[REDACTED]`, and securely handle circular references to avoid crashing the logging utility itself.
