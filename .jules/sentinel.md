## 2024-06-09 - Prevent Sensitive Data Leakage in Logger
**Vulnerability:** The `VueSocketIOLogger` class was directly outputting raw socket payloads and arguments to the browser's console using `window.console`. If sensitive data like passwords or tokens were included in these events, they would be visible to anyone inspecting the console or through third-party error tracking scripts.
**Learning:** Raw event data should never be trusted as safe for logging without sanitization. Even simple client-side logging mechanisms need an abstraction to scrub sensitive keys from deeply nested objects or payloads dynamically. Handling circular references and non-plain objects is critical for preventing logging failures while maintaining observability.
**Prevention:** Implement a recursive data sanitization utility that scrubs known sensitive keys (e.g., `password`, `token`, `secret`) before forwarding arguments to the console, while safely managing circular structures and preserving special types (like Error or Date objects).
