## 2026-03-27 - [Information Disclosure via Debug Logging]
**Vulnerability:** Debug logs in the `VueSocketIOLogger` class directly passed data objects to `window.console.info`, `.warn`, and `.error` methods. When debug mode is enabled, it inadvertently exposes sensitive keys (e.g., passwords, auth tokens, API secrets) from socket events and data payloads directly into the browser's developer console. This is a common issue with frontend libraries that intercept real-time events.
**Learning:** Even if debug mode is intended for development only, developers might unintentionally enable it in production or staging environments, leading to unintended local information disclosure. Additionally, deep nested properties of real-time payloads can easily leak sensitive fields without developers realizing it.
**Prevention:** Always implement a sanitization layer for logging utilities that recursively scrubs plain objects and arrays for sensitive key names (`/password|token|secret|credential|key|auth/i`) before outputting to `window.console`. Handle circular references and preserve native object types (Date, RegExp, Error) to prevent breaking observability or causing memory/call-stack errors.
