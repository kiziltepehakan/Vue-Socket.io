## 2024-05-18 - [Sensitive Data Exposure in Console Logs]
**Vulnerability:** The logger class (`src/logger.js`) logs all data objects directly to the browser console. If applications use this logger and inadvertently include sensitive information (like authentication tokens, passwords, or API keys) in their Vuex or raw socket events, this data will be printed in plaintext to the console, risking exposure.
**Learning:** Adding robust sanitization logic to logging classes is crucial, but doing it on potentially deeply nested or binary structures poses risks of endless loops (circular dependencies) or destroying performance (trying to modify freezing on un-stringifiable binary socket data).
**Prevention:** Always filter known sensitive keywords on logging interceptors while strictly validating if the structures are plain arrays or plain objects. Ensure circular reference handling is managed (e.g. using `Set`) without modifying the original logged reference to maintain true application observability.
