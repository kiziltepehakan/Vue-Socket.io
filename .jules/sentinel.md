## 2024-06-03 - [Information Exposure] Fix unredacted sensitive data in browser console logs
**Vulnerability:** The `VueSocketIOLogger` class logged raw data arrays and objects directly to `window.console` without sanitization. This could leak sensitive variables (passwords, tokens, auth keys) transmitted via Socket.io directly to the client's browser console, posing a high risk.
**Learning:** Even internal logging mechanisms and debugging tools in libraries must handle data defensively. Exposing raw payloads on the client-side can inadvertently leak data to browser extensions or shoulder-surfers. Circular references also need to be handled during recursive sanitation to avoid freezing the browser.
**Prevention:** Implement a recursive sanitization method for all objects/arrays passed to logging mechanisms to redact keys that match sensitive patterns (e.g., `/password|token|secret|credential|key|auth/i`) while ensuring circular references and prototype chains are managed safely.
