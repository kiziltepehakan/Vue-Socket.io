## 2026-06-26 - Prevent Sensitive Data Exposure in Logger
**Vulnerability:** The `VueSocketIOLogger` class in `src/logger.js` passed raw data to `window.console` methods (info, error, warn), potentially leaking sensitive user data (passwords, tokens, etc.) directly into the browser console where it could be visible or captured.
**Learning:** Console logging mechanisms frequently receive large objects or payloads during debugging. Without a dedicated sanitization layer before the `window.console` invocation, sensitive fields are unintentionally exposed. The fix needed to securely handle circular references to avoid infinite recursion and ensure that observability (Error, Date, RegExp objects) wasn't destroyed.
**Prevention:** Implement an automatic recursive sanitization method (`sanitize`) that explicitly replaces known sensitive keys (matching `/password|token|secret|credential|key|auth/i`) with `'[REDACTED]'`. Any logger should strictly pass data through this method before outputting it.
