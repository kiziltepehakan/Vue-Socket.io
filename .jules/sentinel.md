## 2025-02-14 - Prevent Exposing Sensitive Data in Logs
**Vulnerability:** The logger class (`src/logger.js`) in the library blindly forwarded arbitrary arguments to `window.console` methods without any sanitization. Given the library handles Socket.IO payloads, this exposed an application to unintentionally logging sensitive information (e.g., authentication tokens or passwords) present in incoming socket events or user configurations.
**Learning:** Any logging mechanism embedded within a broadly-used library must be defensive against arbitrary data structures, especially when the data originates from external network boundaries like websockets. Additionally, safely traversing arbitrary Javascript objects requires special handling for circular references (via `WeakSet`) and checking that the object is a "plain object" to prevent freezing on binary data or DOM nodes.
**Prevention:** Implement a recursive data sanitizer that inspects object keys against a regex of known sensitive keywords (e.g., password, token) and redacts the values before they are logged.
