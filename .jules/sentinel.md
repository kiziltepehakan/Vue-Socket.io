## 2024-07-16 - Prevent sensitive data leakage in logger
**Vulnerability:** The logger class (`src/logger.js`) previously logged raw socket event payloads and component events verbatim. If sensitive data (like passwords, tokens, auth keys) were transmitted over sockets, they would be written to the browser console when debug mode was enabled, leading to exposure of sensitive information.
**Learning:** Even though logging is disabled by default (`debug = false`), developers or users enabling debug mode could unwittingly expose sensitive application state and credentials stored in vuex or emitted over websockets. Additionally, careless logging of circular references can cause the application to crash, so we must safely handle circular objects.
**Prevention:** Implement a recursive sanitization function that scrubs properties matching sensitive key names (e.g. password, token, secret) from plain objects and arrays before logging, and gracefully handles circular references using a `WeakSet`. Ensure that `VueSocketIOLogger` sanitizes inputs in `info`, `warn`, `error`, and `event` methods.
