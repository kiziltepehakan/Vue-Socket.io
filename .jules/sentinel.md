## 2024-03-13 - Sensitive Data Exposure in Debug Logs
**Vulnerability:** The logger in `vue-socket.io` was logging un-sanitized arguments to `window.console` when debug mode was enabled, which could inadvertently expose sensitive information like passwords, API keys, and authentication tokens in browser environments. This information can be read by malicious browser extensions, XSS scripts, or users observing the developer tools.
**Learning:** Even internal logging mechanisms (especially those dependent on `window.console` in browser environments) need strict parameter sanitization. It's a common oversight to print all arguments during debugging, forgetting the possibility of secrets being included in standard component payloads.
**Prevention:** Implement recursive sanitization functions that remove or redact keys matching sensitive patterns (e.g., `/password|token|secret|credential|key|auth/i`) from any data objects prior to logging. Care must also be taken to handle circular references safely using `WeakSet` or similar mechanics.
