## 2026-06-17 - Sensitive Data Exposure in Debug Logs
**Vulnerability:** The logger class `VueSocketIOLogger` in `src/logger.js` exposed raw Socket.IO events and arguments directly to `window.console` when debug mode was enabled. This could lead to sensitive data (e.g., passwords, authentication tokens) being logged in plain text in the browser's developer console, where it could be exfiltrated by XSS attacks or read by malicious browser extensions.
**Learning:** Browser console logging of framework-level events, even if guarded by a "debug" flag, often receives unstructured and potentially sensitive application state. Libraries routing data to the console must actively sanitize objects. Care must be taken to handle circular references securely without breaking the log output.
**Prevention:** Implement a recursive sanitization mechanism for plain objects and arrays in all generic logging modules, targeting known sensitive key patterns (e.g., `/password|token|secret|credential|key|auth/i`) and replacing their values with `[REDACTED]`.
