## 2024-11-09 - Prevent Sensitive Data Exposure in Logger
**Vulnerability:** The internal `VueSocketIOLogger` was directly passing raw data objects to `window.console` (via `info`, `warn`, `error`, `event`), risking exposure of sensitive information (passwords, tokens, API keys) in browser consoles when `debug` mode is enabled.
**Learning:** Frontend logging utilities must proactively sanitize payloads. It's crucial to correctly handle circular references and strictly process plain objects and arrays to avoid locking up on complex objects (e.g. Vue instances, binary data) while preserving basic types (Error, Date, RegExp) for proper debugging context.
**Prevention:** Implement recursive sanitization before passing objects to console functions. Use regex on keys (e.g. `/password|token|secret|credential|key|auth/i`) to redact values, track visited objects with `WeakSet` to handle circular references, and use `Object.prototype.toString.call` to ensure only plain objects are modified.
