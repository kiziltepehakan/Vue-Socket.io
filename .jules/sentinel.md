## 2026-08-25 - Prevent Sensitive Data Exposure in VueSocketIO Logging
**Vulnerability:** The `VueSocketIOLogger` was directly passing raw WebSocket payload data to `window.console` methods (`info`, `error`, `warn`) when debug mode was enabled. This could expose sensitive client-side information (like authentication tokens, passwords, or session keys) in browser console logs since payloads in WebSockets often contain full event states.
**Learning:** Client-side libraries with custom loggers that intercept wide-ranging events must sanitize all payload data before sending it to the console. Direct delegation of arguments to `window.console` can lead to unintentional leakage of sensitive state.
**Prevention:** Implement a recursive `sanitize` method on any logger that intercepts global or application-wide events. Use regex pattern matching against keys (`/password|token|secret|credential|key|auth/i`) to replace values with `'[REDACTED]'`, while ensuring safe traversal of plain objects and arrays by handling circular references with `WeakSet`.
