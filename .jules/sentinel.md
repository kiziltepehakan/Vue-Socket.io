## 2024-11-20 - [Fix Exposed Sensitive Data in Logs]
**Vulnerability:** Vue-Socket.io logger logged incoming socket events and arguments without sanitization, leading to potential exposure of sensitive data like passwords or authentication tokens in browser console logs.
**Learning:** Overriding console methods or logging wrapper classes need a robust sanitization mechanism. When sanitizing, it is important to prevent infinite recursion via circular references (`Set` was used to track seen objects). Additionally, modifying properties on non-plain objects might freeze execution (e.g. for binary socket data or instances), so the check `Object.getPrototypeOf(obj) !== Object.prototype` was added to only process plain objects and arrays.
**Prevention:** Implement recursive sanitization on logger wrappers for third-party integrations, specifically checking for plain objects before deeply mutating. Ensure keys such as `password`, `token`, `secret`, `credential`, `key`, and `auth` are redacted by default.
