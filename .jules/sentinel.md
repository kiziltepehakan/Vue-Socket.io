## 2024-05-14 - Information Exposure in Console Logger
**Vulnerability:** The `vue-socket.io-v4` logger was printing raw socket event payloads and arguments to the browser console. Websocket payloads can contain sensitive authentication tokens, passwords, and API keys. Because this is a library plugin that enables debug logging across an entire application, exposing this by default is a significant security risk for any consuming application enabling debug mode.
**Learning:** Libraries handling external input streams (like websockets, HTTP requests) must never log raw, unsanitized payloads if there's any chance they contain credentials or PII. Debug logging features in libraries are dangerous vectors for information exposure in production if left enabled or if they indiscriminately dump data.
**Prevention:** Implement recursive data sanitization filters on all logger outputs. Target common sensitive keys like `password`, `token`, `secret`, `credential`, `key`, and `auth`. Ensure sanitization routines handle circular references gracefully (e.g., using `WeakSet`) to avoid crashing the logger itself. Avoid logging unsanitized raw network payloads to the console.
