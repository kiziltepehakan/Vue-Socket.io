## 2024-11-20 - Sensitive Data Leakage in Vue-Socket.io Logger
**Vulnerability:** The `VueSocketIOLogger` was passing raw socket events and Vuex data directly to `window.console` methods when debugging was enabled. This could inadvertently leak sensitive user information (like passwords, auth tokens, or API keys) into the browser console where it could be captured by third-party scripts or malicious browser extensions.
**Learning:** Even diagnostic logging requires data sanitization. Circular references in complex objects (like Vue instances or large Vuex states) can cause recursive logging functions to crash if not properly handled with a `WeakSet`. Additionally, non-plain objects like binary buffers or DOM elements should be skipped during sanitization to avoid freezing.
**Prevention:** Implement recursive object sanitization on all debug/event data before passing it to the console, explicitly checking for keys matching sensitive patterns (`password|token|secret|credential|key|auth`) and replacing their values with `[REDACTED]`. Use `WeakSet` to detect and safely represent circular references.
