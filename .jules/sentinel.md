## 2024-05-24 - [Exposed Sensitive Data in Logs]
**Vulnerability:** The logger in `src/logger.js` logged raw data payloads indiscriminately. This could lead to sensitive information (like passwords, auth tokens, or secrets) being exposed in browser consoles or server logs, violating data protection practices.
**Learning:** When developing libraries that log data payloads from external sources (like Socket.io events or Vuex mutations), it's crucial to proactively sanitize the payload data. Directly logging raw user or system data without filtering is a high-risk practice, especially when the library doesn't control what data it processes.
**Prevention:** Implement a recursive data sanitization method within the core logger module. Ensure it handles circular references gracefully (using `WeakSet`), only traverses safe plain objects/arrays to prevent freezing on binary data, and uses regular expressions to redact known sensitive keys before passing the data to `window.console`.
