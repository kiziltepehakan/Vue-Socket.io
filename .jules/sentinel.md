## 2024-05-18 - Client-Side Logging Data Leakage
**Vulnerability:** The VueSocketIOLogger was dumping raw object references into the browser console without sanitization. In many applications using this library, socket events and data often contain sensitive information like authentication tokens or passwords. Since it was just logging the raw data, this data could potentially be exposed.
**Learning:** Client-side debug logging should never blindy log raw object data, even when 'debug mode' is off by default, because users or developers might enable it and expose sensitive session details to local observers, browser extensions, or error reporting tools that capture the console.
**Prevention:** Implement a recursive data sanitization method (`sanitize()`) for logging that looks for keys matching sensitive patterns (e.g., `/password|token|secret|credential|key|auth/i`) and redacts their values. Ensure this sanitization function handles circular references and does not break native objects like Dates and Errors.
